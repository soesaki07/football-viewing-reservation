# 8. 予約機能

ユーザー：

1. 試合を選択
2. 放映店舗を選択
3. 座席種別を選択
4. 人数を入力
5. 料金確認
6. 予約確定

予約時：

- 空席確認（残席 = broadcast_seat_types.capacity − confirmed予約の人数合計）
- 予約受付期間確認
- トランザクション
- broadcast_seat_types行のロック（lockForUpdate）
- 予約コード発行
- 予約時点の料金保存
- 予約作成時点でconfirmedとして作成（pending状態は使用しない）

---

# 9. 予約管理

ユーザー：

- 予約確認
- 予約キャンセル

店舗：

- 予約一覧
- 予約詳細
- 来店状態更新

予約状態：

- confirmed
- cancelled
- visited
- no_show

予約は作成時点で confirmed となるため、MVPでは pending（保留）状態は発生しない。
