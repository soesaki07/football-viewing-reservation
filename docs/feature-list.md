# 8. 予約機能

ユーザー：

1. 試合を選択
2. 放映店舗を選択
3. 座席種別を選択
4. 人数・備考（任意・200文字以内）を入力
5. 料金確認
6. 予約確定

入口は試合詳細の放映店舗一覧の「予約する」ボタン（予約できる放映で残席が1以上、かつログインユーザーがその試合を予約済みでないときだけ表示。予約済みの店舗には「予約済み」を表示する）。ログインしていれば、ロールに関係なく予約できる。

予約時：

- 空席確認（残席 = broadcast_seat_types.capacity − confirmed予約の人数合計）
- 予約受付期間確認（試合が終了していないことも確認）
- 二重予約の防止（同じユーザーは同じ試合に、店舗をまたいで confirmed の予約を1件まで。座席種別・店舗が違っても1件まで）
- トランザクション
- users行のロック → broadcast_seat_types行のロック（lockForUpdate。この順番で固定）
- 予約コード発行（英大文字と数字の8桁。紛らわしい 0, O, 1, I は使わない）（重複したら最大3回まで作り直す）
- 予約時点の料金保存
- 予約作成時点でconfirmedとして作成（pending状態は使用しない）

# 9. 予約管理

ユーザー：

- 予約確認
- 予約キャンセル

店舗：

- 予約一覧
- 予約詳細
- 来店状態更新

予約状態：

- confirmed
- cancelled
- visited
- no_show

予約は作成時点で confirmed となるため、MVPでは pending（保留）状態は発生しない。

# 10. API同期

Football-Data.org APIとの同期。

対象：

- competitions
- teams
- football_matches

Artisan Command（`app:sync-competitions` / `app:sync-teams` / `app:sync-football-matches`）化済み。
Laravel Schedulerで以下の時刻（JST）に定期同期する（`routes/console.php`）。

- 試合：1時間ごと（毎時0分）
- 大会：毎日 3:30
- チーム：毎日 3:40

同じコマンドの多重起動は防止する。失敗時はログに記録する。
